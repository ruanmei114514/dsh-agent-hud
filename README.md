# @local/agent-hud

把 bilibili 视频 BV1LEWA6cErt（Agent HUD 简约形态，jazzenchen/agent-hud-open）的核心交互移植成 DSH 插件。

悬浮条贴在 **DSH 浏览器窗口**边缘（插件能力边界，盖不到操作系统桌面），可拖到上下左右四边，位置记在 localStorage。默认为两块（全称显示）+ 价格时段 + 一个铃铛：

| 项 | 显示 | 圆环/颜色语义 | 点开 |
|---|---|---|---|
| **DeepSeek Harness** | 24h token（如 `147.2M`） | 24h tokens ÷ 自设预算，<70% 绿 / 70–90% 黄 / ≥90% 红 | 预算条、速率、前24h、调用、会话（不含子 agent）、输入/输出、缓存读取、24h 小时柱、重置统计 |
| **DeepSeek** | 余额（如 `¥42.10`） | 低于预警金额时红环（面板里可开关、可改金额，人民币），否则绿环 | 各钱包、自动刷新开关/秒数、低余额预警开关/金额、立即刷新、更新时间、错误/暂用上次数据提示 |
| **价格时段** | `谷时 5 折 · 2:13:05 后切换` | 谷时绿点 / 峰时黄点 | 当前时段与折扣、剩余时间、下次切换时刻、规则与官方价格页链接 |
| 铃铛 | 待办数 | — | 除当前会话外的其他 DSH 会话：待批准（同意/不同意）、待处理（打开）、运行中、有回复；子 agent 会话不进入铃铛 |

- 审批答复与会话内卡片共享同一个 `PendingApproval`，先答的生效、另一边自动消失；Host 不碰审批流
- 圆环颜色全部走主题 `--dsw-alias-*` token，明暗自适应

## 铃铛的消除规则

- **正常点进去也会消除**：你正在看的会话不算待办。打开会话后由 Host 清掉它的未读标志，铃铛自己就少一条——从侧边栏正常导航同样算，不用非得点铃铛里的「打开」
- **每条旁边的 ×**：「有回复」「运行中」这两类可以手动消除，点 × 只是把它从铃铛里拿走，页面不会跳转
- **全部清除**：面板标题栏一键清掉所有「有回复」「运行中」；**待批准和待处理不会被清掉**，它们要你做决定，漏掉有风险
- 消除只压制**这一轮**：该会话下次完成新一轮（新的完成事件）会自动回到铃铛里，不会被永久忽略
- 消除状态存在 localStorage，刷新页面不复活

> `completionUnread` 是 Host 拥有的只读标志，Client 半没有 API 去写它。所以 × 和「全部清除」记在 HUD 本地（localStorage），不是去改 Host 的标志——对外表现一样（该行不再出现），但 Host 内部那个标志仍要等你真正进入会话才清。

## 峰谷定价提示

按 DeepSeek 官方价格页（2026-10 核对）实现，全部在客户端计算，不改 Host：

- **峰时**：北京时间周一至周五 `09:00–12:00`、`14:00–18:00`，不含中国法定节假日，按标准价
- **谷时**：其余全部时间（含周末、法定节假日全天），按高峰价的 **5 折**
- 芯片里的倒计时每秒刷新，精确到下一次切换；点开面板可看下次切换的**本地时间**、规则和官方价格页链接
- 节假日按内置的 2026 年日历；未覆盖年份按工作日估算，面板会标注

## 重置统计

DeepSeek Harness 面板底部的 **重置统计** 把 24h 统计的起点挪到当前时刻：

- 重置后显示"自重置以来"的用量；满 24 小时后自动回到正常滚动窗口
- 只改显示口径，**不删任何会话日志**；旁边的 **恢复 24h** 可取消重置
- 具体做法：客户端把重置时刻存 localStorage，并在每次 `state.json` 请求里带 `?since=<ms>`，宿主据此裁剪统计窗口

## 数据来源

| 块 | 来源 |
|---|---|
| DeepSeek Harness | `~/.dsh/sessions/**/session.v4.jsonl.zstd`（多帧 zstd，自带 RFC8878 帧遍历器；按 `(size, mtime)` 增量缓存，只重解析变化的文件；日志首行 header `origin:"subagent"` 的子 agent 会话计入 token 但不计入"会话"数） |
| DeepSeek 余额 | `ctx.credentials.resolve('DEEPSEEK_API_KEY')` → `GET https://api.deepseek.com/user/balance`（只读，客户端按"自动刷新 + 秒数"触发，宿主 15s 硬下限 + 单飞 + 上次值兜底） |
| 价格时段 | 内置规则 + 浏览器本地时钟（不联网、不读密钥） |

## 刷新节奏

- **DeepSeek Harness**：客户端每 2 秒拉一次（页面隐藏时暂停，切回立即补一次）；宿主按文件增量缓存，只重算变化的会话
- **DeepSeek 余额**：默认每 90 秒自动刷新（面板内可开关、可改秒数），面板底部还有"立即刷新"按钮
- **价格时段**：芯片每秒走一次表，切回页面时立即校准
- **重置统计**：点按钮立即重拉一次；此后每次轮询都带同一个 `since`，余额刷新也不会把统计口径覆盖回去
- 打开的面板可以多个并存，从悬浮条左边缘向右依次排开；点 × 或再点一次芯片关闭

## 配置（cordis.patch.yml 的 config 层）

`refreshMs` / `balanceMinIntervalMs` / `dshBudgetTokens24h` / `labelHarness` / `labelBalance` / `dshHome`

低余额预警的开关与金额、余额自动刷新间隔都在余额面板里设置（存 localStorage，不占 config）。

## 安装

由 DSH 会话里的 plugin_manager `install_bundle` 安装（目标传本目录绝对路径），或
`dsh plugin --profile web add link:<本目录绝对路径>`。

## 已知边界

- Host 半改动需要宿主重启才生效（替换已加载模块的固有约束）；Client 半是静态文件，刷新即新
- 旧宿主不会返回 `statsSince`，此时重置按钮置灰并提示"重启 DSH 后生效"；重启后按钮才可用
- 峰谷规则若官方调整，改 `client.js` 顶部的 `PEAK_WINDOWS` / `HOLIDAYS_2026` 并刷新页面即可；节假日日历目前只覆盖 2026 年
- 没有 `DEEPSEEK_API_KEY` 时余额块显示 `—`，面板里给出原因，其余功能不受影响
- 采集器按 `agents[]` 数组模块化，后续加 9router/其它服务商只需扩 `collect()`
- HUD 不拦截外部 agent 的审批；答复只覆盖 DSH 自身会话
